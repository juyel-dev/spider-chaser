## Spider Chaser 1.6.0 — first release

Realistic spiders that walk across any web page and stalk your cursor.

**What's in it**
- Walking on 8 legs with a real alternating gait, stalking / pouncing / fleeing
- Web drops: climb off the screen and come back down on a silk thread
- Flies that land on the page; spiders ambush and eat them
- Webs woven strand by strand in a screen corner
- Popup: speed, size, number of spiders (1–6), switches for web drops / flies / webs, "disable on this site"
- Shortcuts: `Alt+S` hide on this tab, `Alt+R` reset positions

**Install**
1. Download `spider-chaser-1.6.0.zip` below and unzip it
2. Open `chrome://extensions`, turn on **Developer mode**
3. **Load unpacked** → choose the unzipped folder
4. Refresh any open page

No data is collected and there are no network requests. See [PRIVACY.md](https://github.com/juyel-dev/spider-chaser/blob/main/publish/PRIVACY.md).
